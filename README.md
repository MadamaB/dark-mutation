# DARK MUTATION — The Post-Human Garden

*Nature did not disappear. It became something else.*

An immersive, scroll-driven 3D experience (Three.js, WebGL, Web Audio). A continuous journey through a living post-human garden:
the abandoned garden, the glass forest, the specimen chamber, the infinite bloom, the new organism, the chrome passage,
fragmented bloom, the vortex and the eternal garden — then back to the beginning.

All geometry, materials and sound are generated in the browser. No voice, no music files.

**Experience it:** open `index.html` through GitHub Pages. Scroll to drift, move the cursor to look and disturb the water. Headphones recommended.
